# ChessLens v1.0.0 privacy

The Stockfish edition does not request camera, photo, or local network access. It has no account, analytics, ads, remote model, or cloud analysis. Chess positions and engine analysis are processed on your iPhone. You can copy a position to the iOS clipboard yourself. The About screen links to source code in your browser.

GitHub hosts the optional download, and AltStore Classic, AltServer and Apple handle installation and signing. ChessLens does not ask for or receive your Apple Account credentials.

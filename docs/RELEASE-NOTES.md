# ChessLens v1.0.0

ChessLens is a free, offline chess position analyzer for iPhone. Set up a board or paste a FEN, play legal moves, and use the built-in Stockfish 19 engine to see the best move and alternatives. No camera scanning, model download, ChessLens account, or internet connection is required to analyze positions.

**Requirements:** An arm64 iPhone running iOS 17 or newer. This unsigned IPA is intended for AltStore Classic. Download it to Files, then open **AltStore → My Apps → +** and select it while AltServer is reachable. Tapping the IPA in Safari does not install it. Free signing generally lasts seven days; refresh from AltStore before it expires.

The corresponding source includes the iOS project, packaging scripts, Stockfish 19 source and native bridge, NNUE evaluation data, and instructions for building and signing a modified app. See the source README and GNU GPL license.
